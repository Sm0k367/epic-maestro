HOW TO DEPLOY
================================================================================

LOCAL DEPLOYMENT (Lenovo):
  1. Navigate to epic-maestro directory
  2. Run: docker-compose up -d
  3. Verify: curl http://localhost:8800/health
  4. Test: pytest tests/ -v

ENABLE CLOUDFLARE SYNC (Optional):
  1. Get Cloudflare credentials
  2. Call: POST /enable-cloudflare-sync with credentials
  3. System syncs decisions to cloud
  4. Works offline if cloud unavailable

CONNECT APPLICATIONS:
  1. POST to http://localhost:8800/orchestrate
  2. Receive intelligent decisions
  3. Or stream via ws://localhost:8800/ws/maestro

MONITOR SYSTEM:
  1. Check: http://localhost:8800/system/info
  2. View logs: docker-compose logs -f
  3. Test API: curl endpoints as needed
